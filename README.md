# claude-dash

A dashboard for Claude Code usage limits and live sessions, built to run in a
cmux Dock pane.

    bun test           # run the tests
    bun run dash       # run the TUI
    bun run snapshot   # print one JSON snapshot
    bun run build      # compile to dist/claude-dash
